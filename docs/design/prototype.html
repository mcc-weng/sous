Draft v1 — 2026-07-29 · clickable, not final code

A working first cut of the persona-tintable token layer plus the three screens carrying the new interactions we've been talking through: the recipe-detail layout from your reference photo, and a real per-step timer + photo-of-dish step in cook mode. The phone screens are deliberately styled dark only — that mirrors the app's actual dark-mode-first decision, not an oversight; this page's own chrome around it still follows your system theme.

Ground: a warm, hue-biased near-black (not pure black) — like char on a wok, not a generic dark UI. Two related accents instead of one lone pop: ember (persona tint — fire/熱血) and gold (highlights, milestones — caramelization, not decoration). Headers use ui-rounded (SF Pro Rounded on-device) for the "軟化" warmth; body text uses the system stack with PingFang TC first, since almost all real copy here is Traditional Chinese.

Recipe Detail

9:41◀ 食譜本
蒜香蔗糖烤肋排

沒有蠔油也沒關係,用醬油、蒜末和蔗糖調出鹹香回甘的醬汁,一樣軟嫩多汁

4
人份

食材

肋排1000 g
醬油3 大匙
蔗糖2 大匙
番茄醬（可省略）2 大匙
蒜末2 瓣
米酒1 大匙

步驟

1調醒醬汁：醬油、蔗糖、番茄醬、蒜末、米酒與白胡椒粉拌勻,讓蔗糖充分融化。
2醃肋排：肋排拭乾,勻勻抹上醬汁,冷藏至少 2 小時,隔夜更入味。
3遠火慢烤：烤箱預熱 160°C,肋排連同醬汁包上鋁箔紙,烤約 45 分鐘至軟嫩。
4調高溫上色：掀開鋁箔紙,再刷一層醬汁,調高溫 220°C 烤 8-10 分鐘至表面焦香上色。
5上桌：出爐後撒上白芝麻裝飾,切塊即可上桌。
小當家秘訣：蔗糖顆粒較粗,醃的時候多抓拌幾下讓它融進醬油裡,才不會烤完表面顆粒沒化開。

What's new here

  • Servings stepper — try it; ingredient quantities recompute live. Real implementation binds to recipes.ingredients[].qty, already stored as {name, qty}.
  • Unit toggle — visual only in this draft; real unit conversion is a scoping question for the spec, not settled yet.
  • Print / copy — maps to the iOS share sheet / UIPasteboard, not new backend.
  • Chef tip merged into the step list rather than a separate section — matches the Discord pain point about not scrolling back and forth.

Teleprompter with a real, working per-step timer (try tapping start — it counts down in real seconds) and a new final "photo of the dish" step before the existing verdict screen. Tip card is fused into the same step card per the Discord feedback, not a separate scroll.
